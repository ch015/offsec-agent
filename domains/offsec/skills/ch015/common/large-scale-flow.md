# Large source assessment

Scanner identifies functional and trust boundaries and assigns every inventory file once. The host validates ownership and creates capacity-bounded Analyzer tasks; it alone admits sessions, retries, and records termination. A model does not create or delegate agents.

Priority surfaces guide investigation depth without excluding the remaining inventory. Each directed cross-unit flow has an endpoint owner. Large files have exact byte/line owners, bounded common definitions, and a bridge review after all range tasks finish. Unsupported parsing and missing context remain explicit limitations.

Every Analyzer must supply delivery receipts and file/flow assessments. Common observations can be shared, but another task's reads do not satisfy the current task. The Reviewer can request scoped missing evidence; repeated unresolved questions remain in the report. A partial report does not make the execution complete.

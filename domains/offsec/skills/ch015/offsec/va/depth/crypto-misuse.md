# Cryptography Misuse 심층 분석 (A5 Depth)

> A5 시크릿/설정 분석에서 암호화 구현이 감지되었을 때
> 목적 적합성과 구현 안전성을 심층 질문합니다.

---

## 적용 조건

```yaml
Trigger: "Phase 1 A5 또는 Phase 2 Cryptography에서 해싱/암호화/서명/난수 사용이 감지된 경우"
```

## 해싱

```yaml
심층_질문:
  - "비밀번호 해싱에 bcrypt/scrypt/argon2 같은 느린 해시를 사용하는가, MD5/SHA256 같은 빠른 해시를 사용하는가?"
  - "Salt가 사용되는가? 사용자마다 고유한 salt인가, 전역 salt인가?"
  - "해시 비교 시 timing-safe 비교(constant-time)를 사용하는가?"
  - "해시 알고리즘 업그레이드 경로가 있는가? (레거시 MD5 → bcrypt 마이그레이션)"
```

## 암호화

```yaml
심층_질문:
  - "대칭 암호화에서 IV/Nonce가 매번 무작위 생성되는가, 고정값인가?"
  - "ECB 모드를 사용하는가? (패턴 보존 — 거의 항상 부적절)"
  - "암호화 키가 코드에 하드코딩되어 있는가, KMS/Vault에서 로드되는가?"
  - "암호화와 인증이 결합되어 있는가? (AES-GCM, ChaCha20-Poly1305) 아니면 암호화만? (AES-CBC without HMAC)"
  - "키 로테이션 메커니즘이 있는가? 이전 키로 암호화된 데이터의 재암호화 경로는?"
```

## 서명

```yaml
심층_질문:
  - "서명 검증 시 알고리즘이 서버에서 고정되는가, 메시지에 포함된 값을 사용하는가?"
  - "서명 대상에 모든 중요 필드가 포함되는가? (금액, 수신자, 타임스탬프)"
  - "리플레이 방어가 있는가? (nonce, timestamp 검증)"
  - "서명 키와 암호화 키가 분리되어 있는가?"
```

## 난수 생성

```yaml
심층_질문:
  - "보안 목적(토큰, 키, nonce)에 암호학적 안전한 난수 생성기를 사용하는가?"
  - "Math.random(), random.random() 같은 비암호학적 PRNG를 보안 목적에 사용하는가?"
  - "시드가 예측 가능한가? (시간 기반, 프로세스 ID 기반)"

놓치기_쉬운:
  부분_적용: |
    대부분의 토큰 생성은 crypto.randomBytes를 사용하지만
    특정 기능(초대 코드, 리셋 토큰)에서만 Math.random() 사용.
  라이브러리_기본값: |
    라이브러리가 기본적으로 안전하지 않은 난수를 사용하는데
    개발자가 인지하지 못하고 기본값으로 사용.
```

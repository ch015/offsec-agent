보안 진단 자동화 시연

핵심 메시지: 대상을 정하고 근거를 수집한 뒤, 검증한 결과를 사람이 판단할 수 있게 만듭니다.

시작

cd demo/security-automation
bash demo.sh serve --open

또는 Finder에서 시연시작.command를 엽니다. 화면은 127.0.0.1:8765, 샘플 서비스는 127.0.0.1:8766입니다. 종료는 실행 터미널에서 Ctrl+C입니다.

“검증된 실행 기록”은 실제 성공 결과를 다시 보여줍니다. 인터넷·API 키 없이 사용할 수 있습니다. “지금 실행”은 새 작업을 수행하며, OffSec·SOC에는 ANTHROPIC_API_KEY가 설정된 터미널이 필요합니다.

발표 순서 · 약 10분

시간화면설명·행동
1분전체 흐름합성 송장 서비스의 소유권 검사 누락을 코드 진단, 웹 요청, 경보 조사로 설명합니다.
1분code-pentester실제 AST 전처리 통계와 8개 진단 영역을 보여줍니다. 독립 분석·Verifier는 Codex/Claude Code에서 실행합니다. 복사 가능한 실행 프롬프트를 제공합니다.
2분web-pentester → 앱 열기내 송장·타인 송장·수정 후 요청의 200/200/403 응답을 비교합니다. 앱은 샘플 서비스와 실제 보안 헤더 검사 결과를 열어둡니다. Traffic·Repeater와 프로젝트 저장을 보여줍니다.
3분OffSec Agent분석·검토·평가·보고서 발행 과정과 파일·줄 근거를 보여줍니다. 원장 심각도와 건수, 발행 조건을 검사한 보고서를 엽니다. 실시간 모델 실행은 수 분 걸리므로 발표에는 준비한 기록을 활용할 수 있습니다.
2분SOC Agent실제 로컬 HTTP 요청과 합성 계정 정보를 조사 도구로 제공합니다. 에이전트가 필요한 조회를 고르고 근거 ID, 한국어 요약, 대응 권고를 반환합니다.
1분마무리범위·예산·도구 실행·발행 검증은 호스트가 관리하고, 사람이 결과와 조치를 검토합니다.

회의 전 리허설

bash demo.sh prepare       # 에이전트 빌드와 웹 앱 파일 확인
bash demo.sh rehearse      # AST + 웹 요청 + 실제 SOC·OffSec 실행
bash demo.sh snapshot      # 성공 결과를 재생용 기록으로 보관
bash demo.sh serve --open  # 발표 화면 열기

OffSec은 한 실행당 최대 4달러·15분, SOC는 최대 8턴·10회 도구 조회·3분으로 제한합니다. 새 실행은 runs/에 별도로 보관됩니다. API 키는 기록에 저장하지 않습니다.

웹 앱은 별도의 시연 프로필과 DB를 사용합니다. 기존 프로젝트와 AI 설정을 변경하지 않습니다.

설명 범위

각 프로젝트의 실제 API·앱을 시연용 어댑터로 연결했습니다. 운영 SIEM 연동, 자동 차단·알림, 완성된 공격·방어 자동 환류 시스템을 의미하지 않습니다. code-pentester의 AST 결과는 최종 취약점 판단과 구분해서 설명합니다.

API 연결이 어려우면 “검증된 실행 기록”을 사용하고, 저장된 기록이라는 표시를 유지합니다.

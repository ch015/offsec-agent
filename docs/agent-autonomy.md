# 에이전트 자율성과 실행 책임

호스트는 준비·소스 스냅샷·Scanner 결과 검증·작업 분할·admission·재시도·취소·저장·완료 판정을 담당합니다. Scanner는 구조적 책임과 교차 흐름의 소유자를 정하며, Analyzer는 명시적으로 배정된 소스 범위에서 조사합니다. 모델의 Agent 호출로 병렬화를 구현하지 않습니다.

관측한 의존 관계가 가설 판정에 필요할 때 허용 목록 안에서 추가 읽기를 합니다. 공통 관측은 공유 저장소에서 찾아 중복 조사를 줄이되 담당 파일 전달과 분석 책임은 유지합니다. 검색 결과·타 단위 claim·Scanner 읽기는 담당 분석의 전체 읽기 증거가 아닙니다.

실행 압박과 429/503은 호스트가 admission과 Retry-After로 제어합니다. 취소 처리 중인 worker는 실제 로컬 종료 전까지 점유합니다. 종료가 불명확하면 보류하고 재시작 전에 확인합니다. 비용은 기본적으로 기록만 하고, 사용량 unknown을 무료 실행으로 간주하지 않습니다.

검토자는 부족한 근거를 범위가 정해진 질문으로 요청할 수 있습니다. 같은 질문의 무진전 반복은 미해결로 남기고 전체 재진단을 반복하지 않습니다. 부분 보고서와 실행 완료는 별개의 상태입니다.

검토가 확정되면 호스트가 판정·근거·심각도·중복 관계를 분류표와 요약 입력으로 직렬화합니다. 보안 판정의 책임은 검토자에게 있고, 평가자는 이 입력을 이용해 전체 위험과 한계를 설명합니다. 분류표의 대량 ID를 모델이 다시 옮겨 적는 작업은 필요하지 않으며, 변경된 검토나 분류표는 무결성 검사에서 거부됩니다.

세부 계약과 한계는 [현재 사용법](../README.md)과 [분석 범위](detection-improvements.md)를 참고하세요.
